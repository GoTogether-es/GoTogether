## 2024-05-24 - Accessibility improvements to the mobile menu
**Learning:** Found an accessibility issue pattern where an icon-only button (mobile menu) was lacking context for screen readers and missing keyboard focus indicators.
**Action:** Always add `aria-label` and focus visibility classes (`focus:outline-none focus-visible:ring-2 focus-visible:ring-blue-500`) to icon-only buttons.
## 2026-05-22 - Notification Bell Accessibility Improvements\n**Learning:** Found an accessibility issue pattern where a custom dropdown component (notification bell) lacked `aria-expanded` and `aria-haspopup` attributes, and interactive items inside the dropdown lacked keyboard focus indicators.\n**Action:** Always add `aria-expanded` and `aria-haspopup` to custom dropdown toggle buttons, and ensure all interactive items inside have focus visibility classes (`focus:outline-none focus-visible:ring-2 focus-visible:ring-blue-500`).
